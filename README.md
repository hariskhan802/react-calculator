# React Calculator

## Overview

**React Calculator** is a modern, responsive calculator application built using React.js. This project demonstrates my proficiency in creating interactive, scalable, and user-friendly web applications. The calculator supports basic arithmetic operations and features a clean, intuitive interface suitable for all users.

---

## Key Features

- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Responsive Design**: Fully functional across all device sizes, from mobile to desktop.
- **Interactive Interface**: Real-time updates with smooth button interactions.
- **Error Handling**: Graceful handling of invalid inputs or division by zero.
- **Lightweight Application**: Optimized for fast performance and quick load times.

---

## Technical Highlights

- **React.js**: Built using functional components and hooks for efficient state management.
- **CSS Modules**: Encapsulated and modular styling for maintainability.
- **Reusable Components**: Modular button and display components for scalability.
- **Prop Drilling**: Implemented state and props management to ensure seamless component communication.
- **Testing**: Includes basic unit tests to ensure reliable functionality.

## Installation

Follow these steps to run the React Calculator on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hariskhan802/react-calculator.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd react-calculator
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the app:**
   ```bash
   npm start
   ```
5. **Open in browser:**
   Navigate to `http://localhost:3000` to view the calculator.
